КАК ИГРАТЬ (без телефона, базовый режим)
-----------------------------------------
1. Открыть SIGame.html в Chrome или Edge (достаточно двойного клика)
2. Загрузить пак вопросов (файл .siq или папку с вопросами)
3. Добавить игроков, нажать «Открыть экран ТВ» для проектора / второго монитора
4. Начать игру!

Установка не нужна. Интернет не нужен. Работает офлайн.


МОБИЛЬНЫЙ ПУЛЬТ (управление с телефона)
-----------------------------------------
Позволяет ведущему сидеть за столом вместе с игроками и управлять
игрой с телефона — не надо оставаться за компьютером.

Сама игра (панель ведущего + экран для игроков) по-прежнему
работает на ПК. Телефон — это просто беспроводной пульт.

Все устройства должны быть в одной Wi-Fi сети.

Требования:
  - Node.js на компьютере ведущего (https://nodejs.org) — один раз

Как подключить:
  1. Запустить скрипт (он поднимает HTTP-сервер И PeerJS):
       Windows  → двойной клик на  start-peer-server.bat
       macOS    → открыть Терминал, перетащить .sh файл, нажать Enter
       Linux    → bash start-peer-server.sh

     Скрипт выведет адрес вида:
       http://192.168.x.x:9000

  2. Открыть этот адрес в Chrome НА ЭТОМ ЖЕ компьютере
  3. Нажать [🎮 Удалённое управление] — появится QR-код
  4. Отсканировать QR-код телефоном — готово!

  Окно/терминал должны оставаться открытыми всё время игры.

  Примечание для macOS: если система блокирует скрипт, выполните
  один раз в Терминале:
    xattr -d com.apple.quarantine start-peer-server.sh


РЕШЕНИЕ ПРОБЛЕМ
----------------
  - Телефон не подключается?
    → Проверьте, что ПК и телефон в одной Wi-Fi сети
    → Убедитесь, что окно сервера открыто и работает
    → Попробуйте отключить VPN

  - Экран ТВ ничего не показывает?
    → Нажмите «Открыть экран ТВ» в панели ведущего
    → Оба окна должны быть в одном браузере (один профиль)
